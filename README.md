A newspaper front page drawn entirely in code: 35 stories from Friday 20 November 2026 in one 1024x1024 image — three illustrated leads, twelve featured stories, a numbered world map, and an "also on" list. The program uses only the Node standard library, with its own PNG encoder and bitmap font, and is fully deterministic.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.png`.
